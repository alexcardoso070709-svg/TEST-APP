# Notion-Import-Anleitung (für Käufer)

1. In Notion: Sidebar → "Import" → "Markdown & CSV" → alle vier `.md`-Dateien auswählen.
2. Notion legt pro Datei eine Seite an. Tabellen werden automatisch zu Notion-Tabellen.
3. Empfohlen: alle vier Seiten unter eine gemeinsame Übersichtsseite ziehen (z. B. "Freelancer-Toolkit"), dann in `01-Freelancer-Finanzuebersicht` die Links unter "Schnellzugriff" auf die echten Unterseiten setzen (@-Erwähnung der Seite eintippen).
4. In `02-Projekt-Tracker`: Spalte "Status" per Klick auf den Spaltentitel → "Eigenschaftstyp bearbeiten" → "Auswahl" umstellen, die 5 Werte aus der Liste am Seitenende als Optionen anlegen. Spalte "Bezahlt" auf "Kontrollkästchen" umstellen.
5. In `03-Rechnungs-Log`: gleiches Vorgehen für "Bezahlt" (Kontrollkästchen) und "Mahnstufe" (Auswahl, 4 Werte).
6. Beispielzeilen (mit "Beispiel:" markiert) vor der eigenen Nutzung löschen.
